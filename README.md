# MisMary

MisMary es una aplicación web que hicimos para ayudar a manejar una tienda informal de venta por catálogo.

La aplicación permite llevar el control de clientes, productos, ventas, abonos, deudas y gastos desde un solo lugar.

## Funciones

* Registrar y administrar clientes.
* Registrar y administrar productos.
* Registrar ventas.
* Controlar abonos y deudas.
* Registrar gastos.
* Consultar historial de clientes.
* Generar reportes de ingresos, gastos y balance.
* Descargar reportes en CSV.
* Inicio de sesión para acceder al sistema.

## Tecnologías

* Python
* Django
* SQLite
* HTML
* CSS

## Instalación

Clonar el repositorio:

```
git clone URL_DEL_REPOSITORIO
```

Entrar a la carpeta:

```
cd Gestion_mismary
```

Instalar dependencias:

```
pip install -r requirements.txt
```

Realizar migraciones:

```
python manage.py migrate
```

Ejecutar:

```
python manage.py runserver
```

## Proyecto

Este es un proyecto académico que estamos desarrollando para mejorar el manejo y control de una pequeña tienda de venta por catálogo.
